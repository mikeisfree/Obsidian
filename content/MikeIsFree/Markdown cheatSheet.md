# **Markdown Cheatsheet**

  

## **1. Text Formatting**

  

- **Bold:** `**bold**` → **bold**

- _Italic:_ `*italic*` → _italic_

- ~~Strikethrough~~: `~~strikethrough~~` → ~~strikethrough~~

- **Bold & _Italic_:** `***bold italic***` → **_bold italic_**

- Inline `code`: `` `code` `` → `code`

  

## **2. Headings**

  

```

# H1

## H2

### H3

#### H4

##### H5

###### H6

```

  

→ # H1  

→ ## H2  

→ ### H3

  

## **3. Lists**

  

### **Unordered List**

  

```

- Item 1

- Item 2

  - Subitem 1

  - Subitem 2

```

  

→

  

- Item 1

- Item 2

  - Subitem 1

  - Subitem 2

  

### **Ordered List**

  

```

1. First item

2. Second item

   1. Subitem

   2. Subitem

```

  

→

  

1. First item

2. Second item

   1. Subitem

   2. Subitem

  

## **4. Links & Images**

  

### **Links**

  

```

[Text](https://example.com)

```

  

→ [Text](https://example.com)

  

### **Images**

  

```

![Alt text](image-url.jpg)

```

  

→ ![Example Image](https://docs.capacities.io/assets/imported-weblink.e172f6fa.png)

  

## **5. Blockquotes & Code Blocks**

  

### **Blockquote**

  

```

> This is a quote.

```

  

→

  

> This is a quote.

  

### **Code Block (Multi-line)**

  

````

```

language

console.log("Hello, world!");

```

````

  

→

  

```javascript

console.log("Hello, world!");

```

  

## **6. Tables**

  

```

| Column 1 | Column 2 | Column 3 |

| Data 1   | Data 2   | Data 3   |

| Data 4   | Data 5   | Data 6   |

```

  

→

  

| Column 1 | Column 2 | Column 3 |

| -------- | -------- | -------- |

| Data 1   | Data 2   | Data 3   |

| Data 4   | Data 5   | Data 6   |

```

```
